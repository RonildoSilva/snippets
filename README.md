# Snippets Python

> Pequenos scripts utilitários em Python reunidos ao longo do tempo: recorte de imagens em partes iguais e percurso de arquivos em diretórios.

![status](https://img.shields.io/badge/status-em%20evolução-blue) ![python](https://img.shields.io/badge/Python-3-blue) ![opencv](https://img.shields.io/badge/OpenCV-imagens-green)

## Conteúdo
| Pasta | O que faz |
|---|---|
| `divide_imagem_2_partes_iguais/` | Divide uma imagem em metades (esquerda/direita e cima/baixo) com OpenCV |
| `divide_imagem_4_partes_iguais/` | Divide uma imagem em quatro quadrantes |
| `percurso_arquivos_diretorios/` | Percorre recursivamente uma árvore de diretórios listando os arquivos |

## Como executar
```bash
pip install opencv-python
python divide_imagem_4_partes_iguais/divide_imagem_4_partes_iguais.py
```
